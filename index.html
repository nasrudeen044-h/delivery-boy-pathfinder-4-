💡 Algorithm Explanation — How Dijkstra Works

Dijkstra's Algorithm is a shortest-path algorithm used to find the minimum-cost path between a starting node and other nodes in a weighted graph.

How it works in this game:

  1. The delivery boy starts from Home (the restaurant).
  2. The customer's location is treated as the destination.
  3. The game map is represented as a graph.
  4. Roads between locations are represented as connections (edges) between nodes.
  5. Each road between two locations has a cost — its distance in km.
  6. Dijkstra's Algorithm calculates the lowest-cost path from Home to the customer.
  7. The game uses that path to determine the most efficient route for the delivery.
  8. A bigger, more tangled city (unlocked as you level up) means more possible routes — and a bigger reward for trusting the algorithm over guessing!
Home → Road → Road → Road → Customer

General idea, step by step:

  1. Give the start node distance 0 and every other node distance ∞ (unknown).
  2. Repeatedly pick the unvisited node with the smallest known distance — that distance is now final.
  3. Look at all roads leaving that node. If going through it makes a neighbor's distance shorter, update the neighbor's distance and remember "came from" that node.
  4. Mark the node visited and repeat until the destination is visited.
  5. Walk backwards using the "came from" links to rebuild the shortest path — this is the green highlighted route you see on the map.
